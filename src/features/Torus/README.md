## Torus

### Description

My first experiment here, adapting a GLSL shader using Skia.

Based on the original app posted by [@baconbrix](https://x.com/baconbrix/status/1924919835420504339), itself adapting a [Clifford torus intersected with a sphere](https://www.shadertoy.com/view/WdB3Dw) from Shadertoy.

### Features

- Skia port of the original GLSL code.
- Rotation matrix and a gesture to control it.
