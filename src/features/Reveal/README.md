## Circular Carousel

SDF-based transition effect built on top of the [Circular Slider](https://www.youtube.com/watch?v=6Va1yBFdUxI&t=47s) code by [Catalin Miron](https://www.youtube.com/@CatalinMironDev/).

All the techniques used in this example were learned from the [GLSL Shaders from Scratch](https://www.simondev.io/courses) course by [SimonDev](https://www.simondev.io/).

### Features

- Circle SDF to swap between two textures with a bit of noise and blur added to the edges to make it look more organic.
- Carousel scroll gesture that swaps the image after its momentum ends
- Looping fling gesture to swap immediately.
